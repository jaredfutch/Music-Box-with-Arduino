# Arduino Music Box with Sensor, LED, and Speaker

> **Status:** Legacy Arduino project. Preserved as a small embedded-systems example.

This project used an Arduino, distance/sonar sensing, an LED, and a speaker in a lighthouse-style build. When motion/proximity was detected, the project triggered light behavior and generated musical notes through the Arduino.

## Demonstrated concepts

- proximity/distance sensing;
- digital output control;
- LED effects;
- simple tone/note generation;
- combining sensing and physical output in one Arduino project.

This repository is retained as an earlier educational/prototyping project and is not presented as an actively maintained Tech-World product.
